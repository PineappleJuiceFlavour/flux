Questions

Common questions

How do I install Flux?
  1. Click Download at the top of this page. It always gets the newest Flux.exe.
  2. Move Flux.exe anywhere you like, for example your Desktop.
  3. Double-click it. There's no installer; Flux sets itself up on first run.
Windows says "Windows protected your PC". Is that safe?

Windows shows this for apps that aren't signed with a paid certificate yet. Click More info, then Run anyway.

Every release is built by GitHub from the public source code. To check a download yourself, run gh attestation verify Flux.exe -R PineappleJuiceFlavour/flux with the GitHub CLI.

My antivirus flagged Flux

A few machine-learning scanners flag new, unsigned launchers because they download files and start games, which is what launchers do. These are false positives.

You can compare the SHA-256 shown on the release page with your file, and read the source on GitHub.

How do I update?

Flux checks for updates when it opens and shows an Update available button in the top bar. Click it and Flux updates and restarts. It only installs an update whose signature matches.

Where does Flux keep my data?

Settings, your library and Minecraft instances live in %LOCALAPPDATA%\FluxLauncher. Sign-ins and keys are kept in Windows Credential Manager, on your PC only.

To start fresh, close Flux and rename that folder.

How do I add my games?
  • Import games in the top bar finds games from Steam, Epic, the Xbox app, GOG, Ubisoft, EA, Battle.net, Amazon and Rockstar.
  • Tools › Add a game adds anything else: drop in a game's file, folder or disc image.
Why can't I pick custom game art? (SteamGridDB key)

Flux finds a cover, background and logo for each game by itself. To choose your own tiles, backgrounds, logos and icons, Flux uses SteamGridDB, a free community library of game art. That needs a SteamGridDB key. It isn't a Steam key, and it's free.

Each key belongs to one person and comes with its own limits, so Flux can't ship one key for everybody. Everyone uses their own, and it only takes a minute to get.

Get your free key:

  1. Open steamgriddb.com and click Log in (top right). It signs in with your Steam account.
  2. Click your profile picture (top right), then Preferences.
  3. Open the API tab and click Generate API Key. (Direct link, once you're logged in.)
  4. Copy the key.
  5. In Flux, open Tools › Art, paste the key and click Save.

Then open a game's Options and use the Art card on the Setup tab to pick a tile, background, logo or icon. Art you pick stays put when Flux refreshes the rest. Your key stays on your PC, in Windows Credential Manager.

A console game won't start
  1. Open Tools › Emulators and check the emulator for that console is installed.
  2. Open the game's Options. The Setup tab says what's missing.
  3. Some consoles need files you dump from your own console, such as a PS2 BIOS or PS3 firmware. Each emulator explains this the first time you run it.

Flux doesn't include or download games. Use copies of games you own.

My PlayStation controller doesn't work in games

Games that only support Xbox controllers need the free ViGEmBus driver. Open Tools › Controllers, click the ViGEmBus link, install it, then turn on controller emulation in Flux.

The Microsoft sign-in page says "Pandora Launcher"

Flux is based on Pandora Launcher and uses its Microsoft sign-in until Flux's own one is approved. Your account still signs in to Flux, and only to Flux.

How do I hide names and messages while streaming?

Turn on Privacy mode in Settings. Friends' names, emails and every chat message are replaced with asterisks until you turn it off.

Is Flux free? Can I see the code?

Yes. Flux is free and open source under the MIT license. The code is on GitHub.
